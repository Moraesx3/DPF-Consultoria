<h1 align="center">DPF Gestão e Consultoria em Saúde</h1>

<p align="center">Site institucional da consultora <b>Daiane Palharini Frana</b>, enfermeira especialista em segurança do paciente e educação permanente em saúde.</p>

## O projeto

Site de uma página para apresentar os serviços, explicar como funciona a consultoria e receber pedidos de diagnóstico pelo WhatsApp e por formulário.

- Layout responsivo, pensado primeiro para celular
- Menu fixo com versão compacta no celular
- "Pulseira de identificação" no topo, referência à 1ª meta de segurança do paciente
- Dúvidas frequentes em acordeão com `<details>`, sem JavaScript
- Formulário enviado sem recarregar a página ([Web3Forms](https://web3forms.com)), com mensagem de sucesso ou erro
- Imagens otimizadas (de ~4 MB para ~200 KB no total)

## Tecnologias

HTML · CSS · JavaScript · GitHub Pages
